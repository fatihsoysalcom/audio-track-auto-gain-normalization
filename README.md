# Audio Track Auto Gain Normalization

This example demonstrates the core concept of 'Auto Gain' or loudness normalization for audio tracks. It simulates multiple tracks with varying initial volume levels and then applies a gain adjustment to bring their perceived loudness to a consistent target, preventing abrupt volume changes during playback. This illustrates the intended functionality of features like rekordbox's Auto Gain.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal using `python main.py`.
